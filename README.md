# NutriControl: protótipo de alta fidelidade

Protótipo clicável, protegido por senha. O `index.html` publicado está cifrado.

Para atualizar: edite `fonte/nutricontrol-prototipo.html` (não vai para o GitHub) e gere de novo:

    node proteger.js fonte/nutricontrol-prototipo.html index.html

Depois faça commit e push do `index.html`.
